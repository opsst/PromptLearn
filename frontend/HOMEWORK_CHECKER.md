# หน้าทำการบ้านและการตรวจวิธีทำ

## ทดลองบน Android Emulator

เข้าสู่ระบบเป็น Student แล้วเปิด **Courses** เพื่อเข้าการบ้าน HW 3.1 เริ่มจากข้อ 1 บนกระดาษเปล่า ใช้ **Previous**, **Next** หรือปุ่มหมายเลขเพื่อเปลี่ยนข้อ ฝั่ง Teacher ใช้หน้า Courses เดิม

- ใช้ปากกาเขียน ไฮไลต์ หรือลบเส้น ยางลบแสดงขอบบริเวณที่กำลังลบและซ่อนทั้งเส้นทันทีที่สัมผัส ใช้ Undo เพื่อย้อนการลากยางลบหนึ่งครั้ง และ Redo เพื่อทำซ้ำ
- ใช้สองนิ้วจีบหรือถ่างเพื่อซูมตั้งแต่ 1× ถึง 4× เมื่อซูมแล้วใช้หนึ่งนิ้วเลื่อนกระดาษได้ การซูมและเลื่อนไม่เริ่ม Automatic Checker และ Snap จะจับภาพกระดาษเต็มแผ่น
- **Snap paper work** จับภาพกระดาษและเรียกตัวตรวจหนึ่งครั้ง เมื่อเปิด **Automatic Checker** แอปรอ 2.5 วินาทีหลังยกปากกาหรือจบการแก้ไข การเขียนต่อจะเริ่มนับเวลาใหม่ ค่าเริ่มต้นของ Automatic Checker คือปิด
- ตัวตรวจจำลองตอบรับภาพที่ส่งเข้าไป กระดาษแต่ละข้อเริ่มว่างและอยู่ในหน่วยความจำระหว่างการล็อกอินเดียวกัน
- คำใบ้แสดงร่วมกับวงหรือเส้นใต้บนกระดาษ โดยเครื่องหมายจากผลตรวจอยู่คนละชั้นกับภาพที่ส่งตรวจ

เลื่อนที่บริเวณโจทย์หรือขอบกระดาษเพื่อดูเนื้อหาด้านล่าง ชื่อการบ้าน ปุ่มย้อนกลับ และปุ่มแจ้งเตือนอยู่ด้านบนระหว่างเลื่อน

## สัญญาเบื้องต้นกับ backend

เปลี่ยนตัวทำงานที่ส่งให้ `PromptLearnApp.homeworkChecker` จาก `MockHomeworkChecker` เป็นตัวเรียก API เมื่อ backend พร้อม ฝั่ง API สามารถรับ multipart ที่มีภาพ PNG และ metadata ตามตารางนี้ รูปแบบ transport และชื่อ endpoint เป็นข้อเสนอสำหรับตกลงร่วมกัน

| ขา | ข้อมูล | ความหมาย |
| --- | --- | --- |
| ส่ง | `questionId`, `prompt` | รหัสข้อและข้อความโจทย์ ให้ backend ใช้รหัสอ้างถึงโจทย์ฉบับจริงเมื่อมีคลังโจทย์ |
| ส่ง | `paper`, `imageWidth`, `imageHeight` | ภาพเฉพาะกระดาษในรูปแบบ PNG ขนาดตามพิกเซลของไฟล์จริง ด้านยาวไม่เกิน 1,600 พิกเซล |
| รับ | `hint` | คำใบ้สั้นเพื่อให้นักเรียนแก้ขั้นต่อไป |
| รับ | `region` | กรอบบริเวณที่ต้องการเน้น ส่ง `null` เมื่อให้คำใบ้ได้แต่ตำแหน่งไม่ชัด |
| รับ | `markStyle` | `circle` เพื่อวงกรอบ หรือ `underline` เพื่อขีดเส้นตามขอบล่างของกรอบ ค่าเริ่มต้นคือ `circle` |

กรอบผลตรวจใช้ `{x, y, width, height}` ในช่วง 0 ถึง 1 โดยอ้างถึงภาพ PNG ทั้งแผ่นและเริ่มจากมุมซ้ายบน Flutter จะตรวจกรอบและวาดเครื่องหมายทับกระดาษตามการซูมปัจจุบัน

## แผนเชื่อมต่อและข้อจำกัด

1. ส่งโจทย์และภาพไปให้โมเดลที่รองรับภาพผ่าน backend แล้วให้ผลเป็น `hint`, `region` และ `markStyle` ผ่าน Structured Outputs ตรวจกรอบอีกครั้งก่อนส่งกลับ เพราะ schema ควบคุมรูปแบบข้อมูล ส่วนความแม่นยำของตำแหน่งขึ้นอยู่กับภาพและโมเดล [Images and vision](https://developers.openai.com/api/docs/guides/images-vision) · [Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs)
2. ทดสอบกับลายมือจริง โดยเฉพาะเลขชี้กำลัง เศษส่วน และตัวอักษรขนาดเล็ก หากอ่านหรือระบุจุดไม่ชัด ให้ส่งคำใบ้ข้อความพร้อม `region: null` ใช้ผลเป็น feedback ระหว่างทำการบ้าน และให้ระบบตรวจตามเกณฑ์อีกชุดเป็นผู้ตัดสินคะแนน
3. ให้ backend จำกัดจำนวนคำขอต่อผู้ใช้และจัดการ timeout แอปส่งทีละงาน รอ 2.5 วินาทีเพื่อรวมการแก้ไข และทิ้งผลที่ตอบมาหลังจากผู้ใช้แก้กระดาษหรือเปลี่ยนข้อ ความหน่วงจริงขึ้นกับเครือข่ายและเวลาประมวลผลของโมเดล
4. เมื่อเชื่อมต่อบริการจริง ให้เก็บ API key ฝั่ง backend และกำหนดนโยบายจัดเก็บภาพวิธีทำก่อนเปิดใช้งานกับนักเรียน
